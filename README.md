# AI Resume Screening Agent

## Project Purpose
The AI Resume Screening Agent is an automated evaluation system developed for the Junior AI Research Associate selection challenge. Its primary goal is to analyze candidate resumes against specified job qualifications, extract key skills and research experience, and assist hiring teams in screening applicants systematically and objectively.
